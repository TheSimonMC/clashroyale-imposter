# Clash Royale Imposter

**Clash Royale Imposter** ist ein spaßiges Social-Deduction-Spiel im Stil von „Among Us“, aber mit Clash Royale Karten! Finde heraus, wer der Imposter ist, während jeder Spieler Hinweise auf seine Karte erhält. Perfekt für Spieleabende mit Freunden.

---

## 🎮 Spielbeschreibung

- Jeder Spieler erhält eine Karte (oder ist der Imposter).
- Imposter müssen die Hinweise clever nutzen, ohne entdeckt zu werden.
- Zivilisten müssen den Imposter aufdecken, bevor er die Mehrheit übernimmt.
- Verschiedene Kartentypen verfügbar: Basis-Karten, Evolution-Karten, Champions und Helden.
- Optional: „Anon Eject“ für geheime Abstimmungen.

## ⚙️ Funktionen

- Auswahl der Spielerzahl (3–12 Spieler)
- Wahl der Anzahl der Imposter
- Kartentypen: Basis, Evo, Champion, Hero
- Interaktives Kartendeck mit Flip-Animation
- Voting-Phase am Ende jeder Runde
- Farbige Spieleranzeige und individuelle Namen
- Hinweise für Imposter-Karten

---

## 💻 Nutzung

1. Öffne die [Spielseite](https://thesimonmc.github.io/clashroyale-imposter/) im Browser.
2. Wähle Spielerzahl, Imposteranzahl und Kartentypen aus.
3. Trage Spielernamen ein.
4. Klicke auf „Spiel Starten“.
5. Jeder Spieler kann seine Karte ansehen, indem er sie gedrückt hält.
6. Nach allen Zügen beginnt die Voting-Phase.
